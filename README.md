# VISONA Travel — сайт агентства

Статический сайт на Astro. Собирается в обычные HTML-файлы, поэтому его можно положить почти на любой хостинг, а позже добавить серверную часть.

## Что внутри

```
src/data/site.json        контакты, реквизиты, ссылки (правится руками)
src/data/countries.json   страны, цены, что входит, сборы, FAQ
src/layouts/Base.astro    шапка, подвал, мета-теги, JSON-LD, cookie-баннер
src/components/LeadForm.astro  форма заявки
src/pages/                страницы: главная, /visa/, /visa/<страна>/, /tseny/, /o-nas/, /kontakty/, /politika/
public/robots.txt         роботы и ссылка на sitemap
astro.config.mjs          домен сайта (site), sitemap
```

Страницы стран генерируются из `countries.json`: добавили объект — появилась новая страница, ссылка в списках и запись в sitemap.

## Команды

```bash
npm install      # один раз
npm run dev      # локально на http://localhost:4321
npm run build    # собрать в dist/
npm run preview  # посмотреть собранное
```

## Что поменять перед запуском

1. `astro.config.mjs` — `site: 'https://ваш-домен'`.
2. `public/robots.txt` — адрес sitemap на своем домене.
3. `src/data/site.json` — телефон, почта, ИНН и ОГРН.
4. `src/pages/politika.astro` — политику проверяет юрист, после этого убрать `noindex={true}`.
5. Счетчик Яндекс Метрики — в `Base.astro` есть комментарий с местом вставки. Скрипт подключается только после согласия в cookie-баннере: оберните его в функцию `window.visonaEnableAnalytics`.

## Как потом прикрутить бэкенд

Форма уже отправляет POST на `/api/lead` с полями `name`, `contact`, `message`, `country`, `consent`, но пока переключена в режим «открыть Telegram». Чтобы включить настоящую отправку, добавьте атрибут `data-live="1"` к тегу `<form>` в `src/components/LeadForm.astro` и поднимите обработчик.

Варианты обработчика, от простого к сложному:

1. **PHP на обычном хостинге** (Beget, Timeweb, reg.ru). Положите рядом с сайтом файл `api/lead.php`, который принимает POST, пишет заявку в файл или БД на том же сервере в России и шлет уведомление в Telegram через Bot API.
2. **Astro в режиме сервера.** Поставьте `@astrojs/node`, в `astro.config.mjs` укажите `output: 'server'` и `adapter: node()`, создайте `src/pages/api/lead.ts`. Тогда фронт и бэк останутся одним проектом.
3. **Отдельный сервис** (FastAPI, Express) на том же хостинге, а сайт остается статикой.

Важно: персональные данные граждан России должны записываться в базу на территории России. Поэтому обработчик формы и база должны жить на российском сервере, а не в зарубежных сервисах.
